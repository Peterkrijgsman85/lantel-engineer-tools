# LanTel Engineer Tools

Statische vanilla HTML/CSS/JavaScript-site voor GitHub Pages.

## Publiceren
1. Pak het ZIP-bestand uit in een GitHub-repository.
2. Commit en push naar de standaardbranch.
3. Activeer GitHub Pages voor de root van die branch.

## Telefoonboek converter
De eerste implementatie ondersteunt LanTel Move CSV naar LanTel Wave CSV. Bestanden worden lokaal in de browser verwerkt.
